# ബാലസംഘം പിണറായി ഏരിയ സമ്മേളനം

Official website for the Balasangham Pinarayi Area Sammelanam.

- **Event**: ബാലസംഘം പിണറായി ഏരിയ സമ്മേളനം
- **Date**: 2026 സെപ്റ്റംബർ 6
- **Location**: കോട്ടയം അങ്ങാടി, കണ്ണൂർ
- **Map**: https://maps.app.goo.gl/rUMkccbTZhMd46Kx5?g_st=aw

## Features

- Malayalam-first, mobile-friendly design with Kerala-cultural visual identity
- Event countdown, gallery, location card with directions, and share actions
- Add-to-calendar (all-day `.ics`), native share with social fallback
- Accessible navigation with smooth scrolling and reduced-motion support
- SEO metadata, Open Graph/Twitter previews, and Event structured data

## Development

You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
